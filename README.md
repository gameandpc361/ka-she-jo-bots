# Kashejo Assistant v4 — GIF / Files / Preview / Diagnostics / Queue Folders

## v4で追加・修正した内容
- GIFをJPEGへ再圧縮せず、読み込んだ元データを保持してWebフォームの`images`添付として送信。GIFはアニメーション画像としてプレビューします。
- 写真アプリ（PhotosPicker）とファイルアプリ（複数選択FileImporter）の両方から画像を選択。
- 選択画像の横スクロールプレビュー、形式・ファイルサイズ表示、個別削除。GIFプレビューは先頭最大40フレームを縮小表示し、投稿データは元のGIF全体を保持。
- 10MiB超過はアプリ側でブロックせず警告のみ。サーバー側の拒否は回避しません。
- キーボードの「閉じる」操作を投稿欄、設定欄、フォルダ名入力欄に追加。
- ログを最大1000行保存。画面遷移・ナビゲーションHTTP応答・フォーム送信メタデータ・応答プレビューを記録し、コピー/テキスト書き出し/共有に対応。
- Cookie、CSRF、パスワード、認証トークン等はログに残さないようマスク。
- 下書きの複数件一括作成（最大10件）。本文中の`{random}`は各下書きの作成時に8文字の英数字へ置換。
- キューフォルダ作成、既存下書きの複数選択・フォルダへの一括移動、フォルダ単位の一括投稿・停止。
- 投稿間隔60〜3600秒、1キュー最大10件。iOS前面での利用を想定。
- 投稿履歴のリンクをアプリ内WebViewまたはiOSの既定ブラウザで開く設定。
- v3で導入したWebフォーム投稿、Live Activity、予約通知を維持。

## GIFについて
この版では、アプリ内でGIFをJPEG化しないように変更しました。選択したGIFデータをそのままmultipartフォームの`images`フィールドへ渡します。ただし、PhotosPicker/ファイルプロバイダが返すデータ形式やKashejoサーバー側の画像処理によっては、投稿後に静止画化される可能性があります。まずファイルアプリから既知のアニメーションGIFを1枚選び、投稿後の表示を確認してください。

## 画像の条件
- 画像データはアプリ側で10MiB超過を拒否しません。超過時は警告を表示します。
- 選択可能な枚数は設定の最大枚数に従います。
- 画像形式はGIF/JPEG/PNG/HEIC/WebP等を想定します。実際に受理される形式はKashejo側の仕様に従います。
- `application/octet-stream`と判定された未知形式は拡張子`.bin`で送るため、サーバー側が拒否する場合があります。

## キューの制限
- 1回のキューは最大10件です。
- 投稿間隔は60〜3600秒です。短時間に大量の同一/ランダム投稿を行う用途には対応しません。
- キューは選択中フォルダ内の下書きだけを対象にします。
- 投稿が失敗した時点でキューを停止します。自動で同じ投稿を無限再試行しません。
- アプリがバックグラウンド/終了中にWebKitフォーム投稿を継続する保証はありません。Live Activityは表示用で、実行時間を延長しません。

## ログについて
ログは通信の全パケット/全サブリソースを完全保存するものではありません。WKWebViewの通常のHTTPSサブリソース通信を安全に完全傍受する標準APIはなく、TLS通信の完全ダンプは秘密情報漏えいにもつながるため実装していません。代わりに、アプリが実行した投稿フォーム送信とWKWebViewのナビゲーションについて、URLパス・HTTPステータス・所要時間・応答プレビュー等を記録します。Cookie、CSRF、パスワード、認証トークンは記録しません。

## 投稿方式
- APIエンドポイントは使用せず、WKWebViewでログインした同一セッション内にある通常の投稿フォームを検出して送信します。
- フォームが見つからない場合、または送信先が別オリジンの場合は中止します。
- 投稿フォームの構造や成功後URLが変わると送信/成功判定に失敗する場合があります。
- 投稿内容はユーザーが用意した本文・画像を使い、サイトの通常フォームを通じて送信します。

## iPhoneだけでIPAを作る
1. ZIPを展開。
2. `github`フォルダを`.github`へ変更。既にリポジトリに`.github/workflows/build-ipa.yml`がある場合は、既存ファイルをこのZIP内の内容で置き換えるか、変更不要ならそのまま使用。
3. リポジトリの同名ファイルをv4の内容に置き換えてコミット。
4. GitHub Actionsの`Build unsigned iOS IPA`を実行。
5. Artifactのunsigned IPAをダウンロードし、SideInstaller等で署名してインストール。
