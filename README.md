# Kashejo Assistant — iOS MVP

KashejoのWeb投稿フォームをWKWebView内で利用するiPhone向け試作アプリです。

## 試作機能
- アプリ内WKWebViewログイン
- 写真ライブラリから最大8枚選択
- Webフォームを検出してmultipart/form-data送信
- 下書き・投稿履歴を端末内に保存
- 最大10件・15秒間隔の連続投稿キュー
- 予約時刻の通知と、アプリ前面動作中の予約投稿

## 重要な制限・未検証部分
- Kashejoの非公開Webフォームに依存します。HTMLやCSRF仕様が変わると動かなくなる場合があります。
- 過去の通信ログで確認した `/a/135/posts` を初期値にしています。アカウントIDが違う場合は `AppModel.swift` の `openPostPage()` を変更してください。
- `images` と `alt_0` などのフィールド名は過去ログに基づく実装です。複数画像をサーバーが同じフィールド名で受け付けるかは未検証です。
- 予約投稿はアプリ前面動作中に実行します。アプリ終了中の厳密な自動投稿はiOSでは保証できません。通知はリマインダーです。
- 投稿成功の判定は簡易判定です。最初は小さい画像1枚のテスト投稿で確認してください。
- このプロジェクトは未署名IPAを生成します。インストール前にサイドロード環境で署名してください。
- Bundle IDは `jp.example.KashejoAssistant` です。必要なら `project.yml` で変更してください。

## iPhoneだけでビルドする流れ
1. GitHubで新しい空のリポジトリを作成します。
2. ZIPを展開し、ファイル一式をリポジトリのルートにアップロードします。
3. GitHubの Actions タブで `Build unsigned iOS IPA` を選び、`Run workflow` を実行します。
4. 完了した実行結果から `KashejoAssistant-unsigned-ipa` artifactをダウンロードします。
5. IPAをiPhoneへ保存し、利用中のサイドロードアプリで署名・インストールします。

## 初回テスト
1. アプリを開き、設定からKashejoへログインします。
2. WebView内で投稿画面を開きます。
3. まず本文だけでフォーム検出を確認します。
4. 次に小さいJPEGを1枚添付してテストします。
5. 投稿履歴とKashejo側の投稿を照合します。

## セキュリティ
- APIキーをアプリへ埋め込んでいません。
- Cookie/CSRFはWKWebViewの同一オリジンセッションを使い、アプリ外へ送信しません。
- Cookieやログイン情報をソースコードやActionsログへ出力しないでください。


## 設定画面
- KashejoサイトURL
- アカウントID（投稿ページの `/a/{ID}/posts` に使用）
- 連続投稿の間隔（5〜300秒）
- 連続投稿の最大件数（1〜50件）
- 写真選択の最大枚数（1〜20枚）
- 設定は端末内のUserDefaultsへ保存します。
- 投稿本文・設定画面の入力中はキーボード上部の「キーボードを閉じる」で閉じられます。画面をスクロールして閉じる操作にも対応します。
